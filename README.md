# Lumi

Ejercicios diarios de lectura, escritura, cuentas y lógica para chicos de 4 a 12 años, en català, español y english.

- App web instalable (PWA): abrila en Safari o Chrome y elegí «Añadir a pantalla de inicio».
- Cuentas de adulto (correo o usuario y clave) con varios chicos por cuenta; el progreso se guarda en Supabase (UE).
- Voces: Piper (es_AR daniela, ca_ES ona, en_GB jenny_dioco), servidas desde Supabase Storage.
- [Privacidad](privacidad.html)

La clave de Supabase de `index.html` es la publicable: los datos están protegidos por Row Level Security (cada cuenta solo ve lo suyo).
